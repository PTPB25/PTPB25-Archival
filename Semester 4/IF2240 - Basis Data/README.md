# IF2240 — Basis Data

<p align="justify">
Mata kuliah Basis Data merupakan pengenalan konsep basis data dan aplikasi sistem manajemen basis data (DBMS). Mata kuliah ini mencakup pengenalan aljabar relasional, model data relasional dan <i>entity-relationship</i> (ER), dan pengenalan SQL. Mata kuliah ini termasuk dalam rumpun Lab Basis Data (Basdat).
</p>
